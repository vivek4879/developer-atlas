# Developer Atlas

Developer Atlas is a collection of the projects I build while completing the
[Scrimba Fullstack Developer Path](https://scrimba.com/fullstack-path-c0fullstack).
Together, these projects document my full-stack development journey.

## The vision

The long-term goal is to turn Developer Atlas into an interactive, map-inspired
experience similar to the exploration maps found in games such as Assassin's
Creed and Far Cry. Visitors will be able to explore the map and discover the
projects, technologies, and milestones from my learning journey.

Developer Atlas is currently in its early stages. For now, each smaller course
project lives in the [`projects`](./projects) folder and can be explored
individually.

## Projects

- [Wild Horizons API](./projects/wild-horizons) — a vanilla Node.js API for
  exploring interesting destinations around the world.

More projects will be added as I progress through the course.
